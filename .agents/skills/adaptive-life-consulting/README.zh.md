# 解决什么问题

很多人习惯找 AI 聊生活里的真实困惑：要不要换工作、该学什么运动、要不要搬家、为什么某个习惯总是坚持不下来。

但普通聊天很容易陷入几种常见问题：换一家 AI 结论就变；你知道“背景信息很重要”，却不知道哪些信息才是真正起决定作用的关键；聊到最后，AI 容易把你的一次主观倾诉直接当成永久的“性格画像”；隔段时间再来，又得把所有前情重新交代一遍。

**Adaptive Life Consulting** 用 Prompt 规则指导咨询判断，并提供 Python 辅助脚本完成工作区初始化、案例建档、记忆校验、结论快照和依赖检索。问题理解、证据判断与实验设计由 Agent 结合情境完成。它的目的，是让 AI 助手像一位靠谱的参谋一样：**陪你把生活里的难题和抉择想明白，并踏实地推向行动。**

# 它不是什么

- **不做心理咨询与诊断**：不提供心理健康评估、人格分析或情绪治疗。
- **不预测未来与算命**：不搞玄学占卜，不假装能预测未来的确定结果。
- **不当盲目顺从的“AI 闺蜜”**：它不会为了迎合你而顺着你的假设给出廉价的安慰，更不会推销某种绝对的“标准答案”。
- **允许说“不知道”与“问错了”**：证据不足时直说不知道；前提不成立时直接指出问题可能问偏了。

# 四个角色的工作法

如果把这套机制具象化，它就像四位各司其职的参谋：

> **苏格拉底负责问，福尔摩斯负责查，富兰克林负责试，张良负责帮你拿主意。**

- **苏格拉底（质疑前提）**：不急着给答案，先看问题本身问得对不对，有哪些未经证实的隐藏前提。
- **福尔摩斯（求证现实）**：不依赖空洞的自我评价，能查客观事实（价格、规则、地点）就去查，判断习惯就看过去真实做过什么。
- **富兰克林（小步实验）**：光靠反复琢磨得不出答案的事，就设计一个成本极低、可以随时反悔的现实小尝试。
- **张良（统筹研判）**：判断哪些未知才真正影响选择、什么时候信息已经足够，以及什么时候该停下思考开始行动。

一句话总结：**该问就问，该查就查，该试就试，重在研判与落地行动。**

# 它是怎么推动对话的

它不会用一套死板的调查问卷来无限盘问你。每当获取关键新信息时，它都会重新思考：

> *当前最重要的未知是什么？什么信息才真正会改变接下来的建议？*

然后动态采取最合适的动作：

- **ASK（提问）**：只问那些只有你本人才知道的关键偏好与硬性约束；
- **RESEARCH（调查）**：需要外部事实时，让 AI 检索价格、规则、地点等真实信息；
- **INSPECT（审视）**：看你过去实际做了什么、查看已有记录，而不是问你“是不是一个自律的人”；
- **INFER（推断）**：基于现有线索提出暂时的合理假设，但绝不把猜测当成既定事实；
- **TEST（尝试）**：光靠分析无法确定的事情，建议一次低成本的现实体验。

随着聊天的深入，问题应该越来越少，结论越来越聚焦。

# 如何使用

本技能需要支持读取技能规则的 Agent；外部调研需要搜索或资料读取工具，持久化案例需要工作区文件读写能力，辅助脚本需要 Python 3。具体技能发现与加载方式以所用产品的配置为准。

## 安装与加载

本技能已按标准规范封装在 `.agents/skills/adaptive-life-consulting/` 目录下：

- **项目级加载**：复制完整技能目录，并按所用产品的要求配置技能路径；支持 `.agents/skills/` 自动发现的产品可从该目录加载。
- **全局安装**：将完整技能目录复制或软链接到所用产品支持的全局技能目录，路径与是否需要额外配置以该产品文档为准。

## 开始第一句对话

不需要任何特定口令，直接像跟一个靠谱的参谋聊天一样抛出你的真实问题即可，例如：

- *“我在纠结周末要不要报名攀岩课，但担心自己坚持不下来。”*
- *“想在三个月内换个城市生活，不知道该怎么选。”*
- *“我想把英语口语练起来，但每次做了计划都半途而废，不知道问题出在哪里。”*

# 记录进展与适时转向行动

## 不用每次从头交代，也不打死板标签

在宿主支持工作区文件读写、且你允许保存记录时，它会帮你跟进复杂的长期决策：聊到一半的想法、试过的小实验、阶段性结论都会被留存下来，下次可从案例继续。不能保存时，它会说明跨会话恢复的限制。

但过去的记录不会变成刻板的“性格烙印”。事实会过期，偏好看情境，旧想法随时可以推翻；只有与当前问题切实相关的事情才会参考。

## 适时停下讨论，转向现实行动

如果继续提问已经不会改变当下的建议，AI 会主动停止追问。

能查清楚的客观事实查完后，如果剩下的未知只能靠亲身体验来验证，它会建议你停止单纯的推敲，直接去做一次低成本的现实尝试。

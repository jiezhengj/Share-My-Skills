# 简介

`adaptive-life-consulting` 是一套纯 Prompt 的适应性咨询技能，帮助 AI 处理选择困难、生活决策、习惯、职业和日常困惑。它会根据当前最关键的未知，动态选择提问、查证、回顾、推断或低成本现实测试。

它不提供心理诊断、不算命，也不把一次主观表达固化为永久人格标签。完整的中文说明和英文说明请分别阅读上方链接。

# Introduction

`adaptive-life-consulting` is a prompt-only adaptive consulting skill for choices, life decisions, habits, careers, and everyday dilemmas. It routes the next step to asking, researching, inspecting past behavior, forming a tentative inference, or running a small real-world test.

It does not provide therapy or diagnosis, fortune-telling, or permanent personality labels. Read the Chinese or English README above for the full introduction.

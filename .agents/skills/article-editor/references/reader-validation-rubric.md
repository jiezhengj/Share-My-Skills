# 读者验证标准

改写目标文档后使用这份标准。把自己当成第一次接触文章的陌生读者。

## 核心问题

仅根据文章本身回答：

1. 读者是谁？
2. 文章处理什么问题或问题意识？
3. 核心主张是什么？
4. 读者读完后能做什么、决定什么或注意到什么？

## 阅读阻力检查

检查：

- 开头没有具体处境，直接给出观点；
- “你”的对象没有定义，或在不同读者之间切换；
- 必要术语在解释前已经出现；
- 段落与上一节的关系只存在于作者脑中；
- 需要阅读其他文章才能理解的系列指代；
- 个人故事没有说明哪些内容可以迁移；
- 结尾只是重复主张，或把承诺推迟到下一篇文章；
- 主张强度超过目标文档中的证据；
- 改写时新增了没有证据支持的事实、例子、数字、来源或因果关系；
- 读者能复述方法，却不知道哪个案例、问题或后果产生了这个方法；
- 概念或理论出现在案例之后，却没有解释案例的转折点；
- 混合型文章从个人观察切换到一般建议时，没有说明迁移边界；
- 多段以第一人称开头，却没有增加行动、观察、判断或责任。
- 过程型文章把某一步的局部成功写成整体取得进展；
- 过程不断查漏或修订，却没有说明收口依据、实际成本和剩余未知。
- 项目复盘连续按“阶段标签—动作—成果”展开，读者无法说出每个阶段独有的对象、动作或判断变化。
- 作者原话中的专业术语、概念词或比喻被误判为模型表达，或在改写中被无依据替换。

## 对向检查（查少与文体身份）

- 文中省略了哪些支撑证据？如果删掉所有顺口的句子，论点是变弱了还是变空了？（查少）
- 文章被写成了什么文体？个人复盘是否漂移成了论文/专栏（对称、每节收束、无时间锚点、句句笃定）？
- 开场是否先透支了结论（主题先置），而不是从"我为什么做这件事"进入？（入口承诺）
- 文中的术语/回指（如"对照组""旧技能"）在使用处，读者能接上所指、参照和来历吗？（回指与术语锚定）
- 是否把"事后才有的认识"写成了"过程中反复对照"？（认识时间线失真）

## 通过标准

只有满足以下条件才算通过：

- 四个核心问题都有清楚答案；
- 文章可以独立阅读；
- 前三节已经建立清楚的阅读路径；
- 每个重要主张都能判断其证据状态；
- 没有添加不受支持的材料；
- 结尾完成了文章自己的承诺；
- 对个人文章或混合型文章，读者无需作者背景就能复原处境、转折、判断变化和案例—方法关系；
- 剩余的第一人称都承担证据、观察、判断或责任。
- 对过程型文章，读者能区分局部结果与整体进展，并知道过程为何停止或转向、停止后什么仍然未知。
- 对项目复盘，读者能区分阶段标签和真实叙述推进；每个主要阶段至少有一个来源明确的对象、动作、观察结果或判断。

## 返回路径

- 缺少作者事实、案例、边界或来源：返回 `interview`。
- 信息已有，但顺序不合理：返回 `brief`。
- 结构稳固，但措辞或衔接不清：返回 `rewrite`。
- 目标路径、记录路径或修改范围不明确：停止并询问。

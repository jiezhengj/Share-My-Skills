`agent-cli-delegation` supports explicit requests to delegate bounded tasks to installed external coding agents. It records observed invocation failures, apparent successes without delivery, and recovery experience. The caller chooses flags and controllable modes using current evidence; examples do not prescribe a single invocation recipe.

See [SKILL.md](SKILL.md) for task agreements, [sessions](references/sessions.md) for continuation and legacy records, [models](references/models.md) for identity and specific fallback choices, and [review experience](references/review.md) for phase confusion and closure. CLI differences: [agy](references/agy.md), [CMDc](references/cmdc.md), [OpenCode](references/opencode.md), [Pi](references/pi.md).

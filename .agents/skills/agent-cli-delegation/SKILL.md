# 使用定位

用户明确要求外部 Agent CLI 执行、评审或检查任务时使用；只问安装、版本、参数或排错时不启动委派。

本技能记录真实调用中的失败、假成功和恢复经验。调用方根据用户目标、宿主能力、当前 CLI 帮助和运行结果自行选择并尝试参数、模式与工具路径；示例不是唯一用法。遇到对应摩擦时参考相关条目，无关检查不必执行。

# CLI、会话与模型

用户点名 CLI 时使用指定 CLI；缺失或无法启动时报告该项，不擅自安装或替换。多个独立意见分别启动外部进程，目标 CLI 的内部 subagent 仅用于用户明确要求的内部子代理任务。

用户要求随机新委派时，从当前可启动、受支持且符合明确限制的候选中用宿主随机工具抽取并报告结果；多个不同 CLI 无放回抽样，候选不足报告缺口。只剩一个直接使用，候选数等于请求数时全部采用。历史成功不证明当前可用；命令解析、帮助或启动检查按未知、环境变化和失败需要执行，当前证据可复用。故障排除依据本轮已知条件，不保存永久黑名单。

无指定或随机要求时，按[会话记录](references/sessions.md)复用有效最近成功 CLI，没有有效选择则询问。“继续刚才/上次某问题”优先定位原会话：当前对话身份→项目关联→可访问的同项目原生历史。唯一匹配即续接，歧义给摘要供选择，找不到说明限制；不要求用户提供内部 ID，不静默新建或跨 CLI 续接。随机与续接意图冲突时澄清。

明确模型按准确 provider/model/variant 传入；未指定沿用默认或原会话模型。模型偏好选型与故障替代见[模型参考](references/models.md)。请求值与原生实际模型分别记录，实际未知为 null。

# 传递任务与选择调用方式

提示词写清目标、材料范围、问题和交付要求；[评审提示](references/review.md)是可选示例。评审交付报告，授权修改的任务写明修改范围及验收条件。不要因“评审”自动叠加只读、禁命令、工具白名单、plan/sandbox 或自定义 Agent；也不要求默认工具或默认权限。用户明确要求零工具尝试时，确认 CLI 能在请求前排除该工具，执行拒绝不证明没有尝试。

从目标项目启动，让 CLI 读取正确材料和项目配置。参数未知或行为不符预期时查看当前帮助及适配参考，不跨 CLI 套用参数。大量材料可由 CLI 在项目中读取，长输入可使用其支持的文件或 stdin 路径。

根据宿主可用接口选择 print/run、逐轮续接或交互路径。持续输入、RPC/ACP/PTY 需要对应的写入、观察和停止能力；可尝试可控路径，并核实实际效果，不把帮助中的入口当成已验证支持。只有启动/输出接口时，单次或精确 session 逐轮调用通常更易控制。

输出模式与权限分别选择。工具密集或需要观察进度时建议事件输出；事件输出不批准工具。调用级参数由调用方在已授权任务和明确限制内选择，无须仅因参数名另请授权。自动批准会取消相应工具审批，不能保证工具只执行任务范围；仍需按任务约束和实际事件核对。实际用户拒绝、明确禁止规则和宿主强制限制继续遵守。持久配置、账号/provider 变更另按用户请求处理。

# 失败、假成功与恢复

退出码或 SUCCESS 不证明任务完成；检查最终交付是否回答要求，并核对必要证据、实际文件变化及未验证项。按任务需要报告 CLI、会话、模型和限制，不为每次委派增加固定审计表。

工具拒绝后，读取具体操作、拒绝原因和执行结果。区分真实用户拒绝、有效禁止规则与 headless 无审批通道导致的自动拒绝；工具错误中的指令式模板不能新增用户禁令。来源不明时继续核实，不把单项拒绝扩大为整个 CLI 不可用或跨会话限制。

在任务范围内选择其他可用工具、调整调用级审批方式或改用可控模式，核对恢复后的执行和交付。阅读可完成材料核查，但不能替代必需的构建或执行验证。重试前检查已完成动作和 session，避免重复副作用。首次失败或单独状态码不证明不可重试；有限再调用本身可检验瞬态失败，无须先有新的外部证据。根据错误信息、重复执行风险、成本、用户限制和连续结果决定是否重试，不强制每次都重试；相同错误持续出现且无恢复迹象或可调整路径时停止当前重复，报告具体阻塞，不无限循环或标记永久不可重试。认证错误与原生重试标记的判断见[模型参考](references/models.md#重试与认证诊断)。

观察进展看新增材料区间、查询、工具结果和证据；重复文件名不证明停滞。根据进展、任务成本及用户期限决定等待、收束或调整方法，不规定统一预算或重试次数。中间结论不能代替最终报告；中止进程不保证服务端取消或动作回滚。

Unknown tool、项目路径不符或宿主动作线索的诊断见[OpenCode](references/opencode.md)与[评审参考](references/review.md)；保留原错误和未知根因，不以线索断言污染。模型/provider 故障见模型参考。当前路径确实无法完成目标时，报告具体未完成项和阻塞。

CLI 差异及事件字段见 [agy](references/agy.md)、[CMDc](references/cmdc.md)、[OpenCode](references/opencode.md)、[Pi](references/pi.md)。

# 安装

需要 Node.js 20+ 和 npm；目标技能目录已存在时，先处理冲突，不要覆盖。在要安装技能的目标项目中，发给 Agent 的指令：

> 请在当前项目执行：`npx degit jiezhengj/Share-My-Skills/.agents/skills/agent-cli-delegation .agents/skills/agent-cli-delegation`

# 适用范围

只在用户明确要求调用已安装的外部 Agent CLI 时使用，例如让 `agy`、`cmdc`、OpenCode 或 Pi 评审、检查、执行或修改边界清楚的任务。用户只询问安装、版本、参数或排错时，不启动委派。调用方需要具备启动进程、观察输出与终止运行的能力；可用调用模式取决于 CLI 和宿主实际提供的控制接口。

# 选择 CLI、会话与模型

- 用户点名 CLI 时使用指定 CLI；当前命令缺失或无法启动时说明并停止，不擅自替换或安装。选择和启动前检查当前命令与可启动性，残留 shim 或旧成功记录不作为安装证明；可启动不代表认证、模型或服务可用。
- 新委派明确要求“随机 CLI”时，用宿主随机工具从当前可启动、受支持且符合任务硬限制的候选抽取一个，报告候选与结果；一个直接用，零个说明不可执行，不因失败无限重抽。多个不同 CLI 无放回抽样，候选不足报告；数量相等时全部采用，随机只影响顺序。每轮重新检查，故障排除仅作用于本任务已知条件，不保存永久黑名单。随机优先于旧默认；与原会话续接意图冲突时先澄清，不随机跨 CLI 续接。
- 新委派未点名且未要求随机时，读取项目根目录 `.agent-cli-delegation.json` 的最近成功选择，并持续兼容旧 `.headless-agent-delegation.json`。没有有效且当前已安装的选择，或新旧选择存在未解决冲突时，询问用户。CLI 卸载不自动删除旧选择或历史；原 CLI 不可用则无法原生续接，用户接受后才可带背景用另一 CLI 新建。
- “继续刚才”“接着上次某问题”表示续接。先从当前对话、项目关联和可访问的同项目原生历史定位会话，核对项目、完整身份、主题、结果与运行状态；唯一且无冲突时续接，多候选时提供摘要供选择。找不到时说明限制，不静默新建，也不要求用户提供内部 session ID。
- 用户明确要求独立意见、新会话或 fork 时，建立新关联。一次点名多个 CLI 时，分别启动独立外部进程；目标 CLI 的内部 subagent 只在用户明确要求时使用。
- 用户明确指定模型时，先核对准确的 provider/model/variant；未指定时沿用 CLI 默认或原会话有效模型。仅有“便宜”“思考能力强”等偏好时，请用户指定模型，不自行排名或代选。区分请求模型与原生实际模型，实际身份未知时记录为 `null`。

# 执行任务

- 提示词写清目标、范围、待回答的问题和所需结论。普通评审使用 CLI 默认工具、权限和配置，不因“评审”自动添加只读模式、工具白名单、sandbox 或自定义 Agent。修改文件须由用户明确授权，并写清范围和验收条件。
- 从目标项目根目录启动，保留项目配置、账号、provider 与当前运行环境。大量文件让 CLI 在项目中搜索和读取；不要把整份仓库拼进提示参数。
- 首次调用前检查当前 CLI 帮助，分别选择可用权限路径和输出模式。多文件、多轮、工具调用或需要观察进度的任务，从首次调用就使用事件输出；事件输出不增加工具权限。
- 默认采用单次调用或明确会话的逐轮续接；独立进程不绑定 headless/print。有已验证交互控制时可选择交互，持续 stdin、RPC、ACP 或 PTY 要求宿主具备双向控制、输出观察、取消和原生会话核对并实际验证。
- 按[阶段评审与收束](references/review.md)写明阶段、必查项、证据阻塞和结案。依据材料区间/查询/步骤及新增证据观察进展，预设本轮预算；停滞最多一次收束，仍停滞交部分结果与限制。只在新增证据、阻塞、恢复或终态时更新。
- 用户明确要求禁止尝试某个工具时，先确认 CLI 能否实际排除该工具。运行时拒绝不等于没有发起请求。
- 退出码或协议成功状态不代表任务完成。检查最终答复是否给出要求的结论、证据和格式，并核对实际文件变化。交付时报告 CLI、调用方式、会话方式、请求与实际模型、替代依据和未验证事项。

# 记录与故障恢复

项目记录只保存精简会话关联、结果摘要和最近成功 CLI，不保存完整提示、答复、凭证或永久权限。用户禁止项目写入时，在当前对话中维护关联并说明跨宿主恢复限制。旧选择记录持续兼容，不自动删除。

失败或工具拒绝后，先核对原生事件、已执行动作、部分成果与会话状态，再处理具体受阻操作。可启动、可读材料、可执行命令与本任务完成分别取证；命令拒绝不整体淘汰 CLI，文件核查不替代必需实测。Unknown tool 或宿主动作线索先暂停核对项目/工具/配置，未知根因如实保留，不断言污染。固定模型失败默认停止换模；只有用户明确给出具体替代候选及有限顺序时才依次尝试，每个替代候选最多一次。无法保持上下文时，先取得用户对带背景新委派的接受，避免重复已经执行的动作。

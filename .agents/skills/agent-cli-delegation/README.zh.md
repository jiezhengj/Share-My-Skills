# 用途与调用

用户明确要求已安装的 agy、CMDc、OpenCode 或 Pi 执行、评审或检查任务时使用。技能记录真实调用摩擦，帮助调用方识别失败和假成功、选择恢复路径；调用方可根据当前能力、帮助和运行结果自行选择参数与模式。只问安装、版本或排错时不启动委派。

可点名 CLI、要求随机多个不同 CLI，或用“继续刚才/上次某问题”续接。调用方定位原生会话，不要求人类提供内部 ID；无有效默认选择或有歧义时询问。多个独立意见分别启动外部进程。

模型明确指定时使用准确身份，未指定沿用默认或原会话模型；本技能不按便宜/强推理等偏好代选。失败替代只按用户给出的具体候选顺序。

# 经验重点

- 工具密集任务可用事件输出观察进展；事件输出不增加权限。帮助和启动检查按未知、环境变化或失败需要执行，无需每次重复。
- headless 自动拒绝可能使用 user denied 模板，须结合真实指令、有效规则及 CLI 诊断识别来源；模板不新增用户禁令。调用级审批参数可在已授权任务内自主选择，真实用户拒绝和强制限制继续遵守。
- 评审不自动叠加限权，也不要求默认权限。`SUCCESS`、退出码和中间 PASS 不证明完成，核对实际证据与最终交付。
- 重复文件名不证明停滞；根据新增证据、方法变化和成本决定等待、收束或恢复，无统一次数。

项目记录只保存精简关联和摘要，兼容旧选择记录，不保存凭证、完整历史或永久权限；禁止项目写入时可在当前对话维护关联。

# 识别模型与可用性

用户明确指定模型时，解析为准确 provider/model/variant；名称对应多个身份时展示候选及区别，请用户选，不凭近似字符串决定。未指定沿用 CLI 默认或续接会话的有效模型，不主动优化。

本技能不自主按“便宜”“思考能力强”或“根据任务智能选择”代选，也不维护能力/价格对比表或运行时排名。仅有这些偏好时，说明目前不能可靠代选，请用户指定模型；确定前不启动委派，也不把默认模型说成满足偏好。模型目录可用于身份消歧，不能用名称或 thinking 标签证明更便宜、更强或更适合任务。

区分目录可见、已有账号/权限信号与本轮实际调用成功；每层不能代替下一层，认证不代表模型额度。实际身份只取原生事件/session 消息字段，未知为 null，不用请求值或模型自称冒充。不为测试创建账号、provider、配置或付费。

# 识别故障与具体替代授权

先读取原生错误、最终结果、已执行工具和 session 状态。配额错误只说明本次请求；核对完整 provider/model 与既有路由，不推断整个账号余额。

| 故障 | 处理 |
| --- | --- |
| 模型不存在/不可用、模型局部额度或局部限流 | 默认报告并停止换模；有具体候选及顺序授权时才执行该顺序 |
| 认证、账号权限、整体额度 | 核对具体路由、原生错误及恢复信息；按下节判断有限重试，不单凭类别封禁，也不盲目换模或变更账号 |
| 工具权限 | 见主技能及 CLI 适配；自动拒绝可调整调用级参数，不以换模解决 |
| 连接/服务故障 | 判断是否瞬态，核对已执行动作后决定原模型重试，不单凭连接故障换模 |
| 无法确定类别 | 保留未知，可继续有依据的诊断或重试；未知本身不授权换模 |

“用 A”默认固定；“同档替换”“找便宜替代”及其他泛化偏好都不足以决定具体模型。用户明确说“A 不可用就用 B”，或给出有限候选顺序时，可按该具体授权执行，不再自行证明同档、不补充候选。按候选顺序执行，不无限循环失败候选；原模型或当前候选的有限诊断重试见下节，不要求先有新的外部证据，也不因此增加候选。进程重启或上下文转移不重置用户候选范围。保持同 CLI、既有 provider；跨 provider/CLI 需具体授权且已有配置可用，不创建或切换账号。

具体候选授权不抹去用户另给的预算、工具/模态等明确限制。无法核对限制时说明未知并取得对具体选择及未知项的接受；不宣称替代模型能力等价、同价或成本不升。模型身份无法唯一解析时先澄清。

# 重试与认证诊断

以下适用于 agy、CMDc、OpenCode 和 Pi。首次失败、401 或其他单独状态码只证明本次请求失败；结合原始消息、完整路由、CLI 恢复信息和已执行动作判断，不能直接认定模型/CLI/会话不可重试。有限再调用可以检验暂时失败，不必先取得新的外部证据；是否适合重试同时考虑重复执行风险、成本和用户限制。对可能已执行的修改先核对结果，不能盲目重放。

原生日志若给出 retryable=false、non-retryable 等标记，引用实际来源及作用范围，区分 CLI/SDK 内部自动重试策略与宿主再次发起调用；标记不是用户禁令，也不保证宿主再调用有用。没有原始字段时，不声称 CLI 已标记不可重试；宿主决定本轮停止须说明自己的依据。

401 表明本次认证未被接受；核对既有 provider 路由和非敏感状态，留意原生提示是否涉及暂时状态、既有机制刷新或明确持续凭证失效。不承诺每种 CLI 都有自动刷新。保持现有账号/配置的诊断及有限再调用，与重新登录、修改凭证/配置或切换账号/provider 分别判断；不修改登录配置不等于禁止重试。

若证据明确持续失效且需要用户登录，或连续相同错误无恢复迹象、无可调整路径，停止当前重复调用，说明恢复所需条件。一次失败不推出永久不可重试，也不无限重复；不设跨 CLI 通用次数阈值，不强制每种错误都试第二次。用户明确禁止重试或宿主硬限制仍遵守。

报告原/新模型、故障证据、具体授权和已尝试候选。恢复前核对部分成果、副作用与完整 session，保持任务、项目与用户明确限制；调用级权限方式可按需要调整；无法保持上下文时先接受带背景新委派，不静默新建或盲目重放动作。关联恢复见 [sessions](sessions.md)。

# 从自然语言定位原生会话

“继续刚才登录问题”“接着上次用 Pi 的评审”属于续接意图，不要求用户说出 session ID。先确定用户所指项目与 CLI，再按当前对话已捕获身份→该项目精简关联→可访问的同项目原生历史查找。查询历史和列摘要本身不是委派。用户明确指向其他项目时，核对该项目可访问且候选原生项目匹配后才能续接；不同机器路径不能直接认定同一项目。

逐个核对 CLI、原生项目、完整定位、主题、最后结果/未完成项、时间和运行状态。只有完整身份可核对、项目相符且其他线索无冲突时自动选唯一候选；仅有一个目录条目或最近时间不足以认定。多候选给用户简短主题/项目/时间/结果摘要供选择；没有候选说明未找到并询问是否带背景新建，不静默新建。短 ID 须先解析为唯一完整 ID。用户明确要求独立意见或新会话时建立新关联；fork 也是新身份。

运行前重新确认原生会话存在。被删除或不可访问标为 unavailable，关联记录不是存在证明。检查当前可观察的进程/原生状态；同一会话已有其他修改任务时先等待或选择独立会话，不发送第二个修改任务。不声称能检测其他宿主全部活动，也不新增锁服务。原生发现接口不可用时说明范围，依然可使用已捕获完整定位进行明确续接。适配参数见各 CLI 参考。

# 精简项目记录

根目录 `.agent-cli-delegation.json` 使用以下约束，记录只用于恢复关联，不保存完整提示、答复、凭证或永久权限。

| 字段 | 约束 |
| --- | --- |
| schema_version | 整数 1 |
| last_successful_cli | agy/cmdc/opencode/pi，可缺失；仅真实完成后更新 |
| sessions | 精简关联列表，可为空 |
| legacy_choice_resolution | 可缺失；保存已由用户解决冲突时的旧 CLI 值与选定新值，不含凭证；旧值未变化且新值仍匹配时不重复询问 |

| 会话字段 | 约束 |
| --- | --- |
| cli | 支持的 CLI 标识 |
| native_project | 原生项目标识或可核对项目目录；不同机器路径不能直接当同一项目 |
| session_id / session_path | 至少一个完整原生定位值；前缀必须先解析唯一 |
| topic | 用户可理解的任务主题 |
| summary | 简短结果及未完成项，不复制完整提示/答复 |
| created_at / updated_at | 含时区的时间 |
| status | active/completed/incomplete/unavailable，最后已知状态，运行前重新核对 |
| requested_model / actual_model | 可缺失；实际未知明确 null，不用请求值冒充 |
| origin | delegated/native-discovered |

主键是 cli＋native_project＋完整 session 定位，不是主题。首轮捕获原生身份后保存关联；续接只更新同一关联。写入前重读，按主键合并且保留根对象、其他会话及本会话的未知字段；若同时发生变化，重读后重新合并，不能用旧快照覆盖。使用同目录临时文件原子替换。JSON 损坏、字段类型不合法或 schema_version 未知时，不覆盖，报告恢复限制并使用当前对话可验证的身份。

用户禁止项目写入时不保存记录并说明跨宿主恢复限制；仅要求外部任务做只读评审，不自动视为禁止保存委派关联。不能写项目时可在当前对话维护精简关联，但不能声称新宿主一定找得到。

默认保留精简关联至用户清理，不自动按时间删。清理指定关联只删除对应 sessions 条目，保留其他条目和未知字段，不删除原生历史。委派记录不是技能共享依赖，不随技能分发到其他项目。

# 旧选择持续兼容

持续读取 `.headless-agent-delegation.json` 的有效 last_successful_cli，不自动删旧文件，不设期限。新记录不存在或未给出有效选择时继承旧有效选择；新旧一致直接使用；新旧有效但不同，先看 legacy_choice_resolution 是否同时匹配当前旧值与当前新选择，匹配则沿用已确认新选择，否则询问一次并保存用户确认的旧值及选定新值。旧值变化或新值不再匹配时重新核对。旧 JSON 损坏则报告并保留，不能重写修复或让它覆盖有效新记录。未知字段保留。

# CLI 卸载或当前不可用

last_successful_cli 只记录历史成功，不证明当前安装。新委派核对当前命令与可启动性；旧默认不可用时询问可用选择，不自动删除或改写旧选择，仅在真实完成新任务后更新成功值。随机新委派按主文从本次可启动候选抽样，不受旧默认约束。

续接所需 CLI 不可用时说明无法原生续接，即使历史文件仍在也不能交给另一 CLI 当原会话继续；保留关联和原生历史，不把 CLI 不可用等同于历史被删除。用户接受后才可用其他 CLI 带背景建立新关联。随机与原生续接意图冲突先澄清，不随机迁移 session。

# 失败与恢复

部分失败先从原生事件核对哪些操作已执行、最终结果和会话是否可续接；更新 summary 和 incomplete，不把退出码当交付。重试或获授权模型替代保留范围、权限、验收条件与完整 session；不能保持上下文时，先由用户接受带必要背景的新委派，再新建关联。已经产生的文件或外部动作不得盲目重放。用户具体授权的有限替代顺序跟随当前任务，每个替代候选最多一次，进程重启或上下文变化不重置；项目摘要不持久化为替代授权，不自主补充候选。

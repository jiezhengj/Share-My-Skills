`headless-agent-delegation` delegates a task to an installed external coding agent only when the user asks for it. The skill keeps ordinary reviews simple: state the goal, scope, question, and expected report; use the target CLI's normal defaults and project context. CLI-specific calls and event fields are in [SKILL.md](SKILL.md) and `references/`.

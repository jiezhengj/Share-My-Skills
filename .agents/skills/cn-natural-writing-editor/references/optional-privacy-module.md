# 可选脱敏模块

用途：只在用户明确要求脱敏、匿名化或隐藏身份信息时读取。它不属于去 AI 味儿的默认流程。

适用条件：用户明确说“请脱敏”“不要暴露真实项目/软件/路径/账号”等。

不适用条件：用户只说“去 AI 味儿”“改得自然”“保留我的语气”或“不要套话”。这些请求不得触发本文件。

## 操作原则

保留事件结构，替换身份信息：

```text
真实项目或软件名 → 通用类别
真实模块名 → 功能角色
真实设备名 → 设备 A / 设备 B
账号、仓库和路径 → 删除或替换为说明
动作、结果、失败和限制 → 尽量保留
```

脱敏后检查：

- 读者是否仍能反推出真实对象；
- 是否把真实经验改成了虚构案例；
- 是否因为删除细节使结论变得过强；
- 是否需要标注“例子已做匿名化处理”；
- 哪些事实因脱敏而变成 `UNKNOWN`。

如果证据减弱，降低结论强度，不补一个看起来完整的新细节。只有启用本模块时，才在交付报告中写替换记录和反推风险。

## 目标

在写正文前，把读者、材料、判断和边界固定下来。默认不生成完整成稿。

## 输入

可以是主题、聊天记录、语音转写、零散笔记、参考文章、个人经历或一个待解释的问题。

如果只有一个宽泛主题，先提问，不要用通用背景和“三个方面”填充。

## 素材地图

把每条材料标记为：

| 标记 | 含义 |
| --- | --- |
| `EXPERIENCE` | 作者亲自经历或操作过 |
| `OBSERVATION` | 作者或来源观察到的现象 |
| `FACT` | 可核验事实、数字、引用或时间 |
| `INFERENCE` | 根据材料做出的推断 |
| `RECOMMENDATION` | 给读者的建议 |
| `UNKNOWN` | 缺少信息或尚未确认 |

用以下格式记录：

```text
材料：
类型：EXPERIENCE / OBSERVATION / FACT / INFERENCE / RECOMMENDATION / UNKNOWN
支持什么判断：
范围或限制：
需要作者确认：
```

## 中心判断

要求作者先形成一个可以被不同意的判断，而不是只给主题：

```text
主题：
中心判断：
为什么这样判断：
最强支撑材料：
可能推翻它的情况：
文章不准备解决的问题：
```

如果中心判断只有“应该重视”“需要协同”“未来值得期待”，继续追问具体对象、动作、后果和取舍。

## 提纲

提纲应从材料形成，至少说明每节的功能：

```text
开头：从哪个场景、矛盾或问题进入？
第一节：增加什么新信息？
第二节：哪个动作或证据推动判断？
第三节：有什么反例、失败或限制？
结尾：完成哪个判断或给出什么最小行动？
```

不要为了形式完整强行凑三节、三个例子或一个拔高结尾。

## 风险预警

写作前标出：

- 可能被写成宏大背景的地方；
- 缺少真实材料、只能提问的地方；
- 容易把经验扩大为规律的判断；
- 可能出现同义复述、列表滥用或强行总结的段落；
- 可能把感受写成标注（“我很焦虑”）而不是承载（处境与后果）的地方；
- 可能补氛围性细节（盯着看、深夜、反复）代替功能性事实（谁、多久、结果）的地方。

脱敏不属于默认风险预警。只有用户明确提出脱敏时，才读取可选隐私模块并单独记录身份风险。

## 停止标准

满足以下条件后才进入 `drafting`：

- 读者和文章类型明确；
- 中心判断可以用一句话说清；
- 主要材料都有类型标记；
- 缺失信息已提问或标记为 `UNKNOWN`；
- 提纲说明了每一节增加什么信息；
- 作者确认可以开始写作。
